# Landing page — Layla Coelho Dalossi Amaral

Site estático pronto para publicar na Vercel. O arquivo `index.html` está na raiz e as fotos estão em `assets/`; não há dependências nem etapa de build.

## Publicar

1. Acesse [vercel.com/drop](https://vercel.com/drop).
2. Envie o arquivo ZIP completo ou esta pasta.
3. Escolha o time e o nome do projeto e clique em **Deploy**.

Para manter o mesmo endereço ao publicar futuras alterações, conecte um repositório Git ao projeto Vercel.
